# Bela Cris · Nail Designer

Landing page da Bela Cris — manicure, pestanas e depilação a cera fria em Lisboa.

## Antes de publicar
1. Abra `script.js` e troque `351900000000` pelo seu número de WhatsApp (com indicativo 351, sem + nem espaços).
2. Em `index.html`, procure por ✏️ para trocar o utilizador do Instagram e, se quiser, a morada no mapa.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `belacris`).
2. Envie todos os ficheiros desta pasta (incluindo a pasta `assets` e o ficheiro `.nojekyll`).
3. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em 1–2 minutos o site fica disponível em `https://SEU-UTILIZADOR.github.io/belacris/`.

## Estrutura
```
index.html      página
style.css       estilos
script.js       número de WhatsApp e mensagens
assets/         logótipo, favicon e imagem de partilha
.nojekyll       evita processamento Jekyll no GitHub Pages
```
